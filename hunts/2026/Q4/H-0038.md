### Hypothesis Statement

Adversaries use ClickFix social engineering to trick macOS users into pasting a Terminal command that downloads and executes a hidden Bash loader, which fetches architecture-specific Go-based stealer binaries and establishes LaunchAgent persistence, in order to position credential and cryptocurrency wallet harvesting capabilities on macOS endpoints.

### Justification

The Huntress incident report documents a real victim tricked into running a Terminal command that retrieved a Bash loader from 193[.]29[.]224[.]151, which in turn dropped Go-based stealer executables (ARM64: f0062f7e70e61493684a2f60748a475168e155bc2502163c844c42e87692abd0; x86_64: 619a99ba4ee9d7f33db8045c7e03c4265424977993fe8a53b0f45157c5abd3e5) and registered a LaunchAgent at /Users/m1/Library/LaunchAgents/com.apple.softwareupdated.plist for persistence. The malware masquerades as Apple system processes (com.apple.verified, com.apple.homeenergyd) and communicates with a C2 at 138[.]124[.]118[.]69:8133/tcp over plain HTTP on a nonstandard port. The ClickFix delivery bypasses technical controls entirely by abusing user action in Terminal, making process-lineage and file-event telemetry the primary detection surface. The LaunchAgent persistence mechanism ensures the stealer survives reboots, extending the window of exposure. Any macOS endpoint where a user browses to a ClickFix lure page is at risk regardless of patch level.
