## 1. System Research: How It Works

### Summary
Apache Roller serves a web application that includes an XML-RPC API endpoint (/roller-services/xmlrpc) which, in vulnerable versions (4.0.0-6.1.4), deserializes unauthenticated vendor extension types (ex:serializable) before authentication checks occur. This allows unauthenticated remote attackers to execute arbitrary code by exploiting Java deserialization vulnerabilities via the XML-RPC protocol.

### Key Findings
- The vulnerability affects Apache Roller versions 4.0.0 through 6.1.4, with a critical CVSS v3.1 base score of 9.8 due to unauthenticated remote code execution capability.
- Exploitation targets the pre-authentication deserialization of XML-RPC requests at the /roller-services/xmlrpc endpoint, specifically leveraging the ex:serializable vendor extension type.
- Public proof-of-concept exploits utilize Java gadget chains such as CommonsCollections5 to achieve remote code execution, often using two-stage approaches or shell command injection for persistent access.
- Mitigation requires upgrading to Apache Roller 6.1.6 or later; interim controls involve disabling the XML-RPC feature or restricting network access to the XML-RPC endpoint.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit CVE-2026-129448, a critical unauthenticated remote code execution vulnerability in the Apache XML-RPC endpoint of internet-facing Apache Roller installations (versions 4.0.0–6.1.4), to achieve initial access. The attack leverages unsafe Java deserialization via malicious XML-RPC requests, triggering arbitrary code execution without prior authentication.

### Key Findings
- CVE-2026-129448 is a critical (CVSS 9.8) unauthenticated RCE vulnerability caused by unsafe XML-RPC deserialization and unconditional servlet registration in Apache Roller versions 4.0.0 through 6.1.4.
- The vulnerability is being actively exploited in the wild as of November 17, 2026, with the Apache Software Foundation confirming active exploitation before releasing a fix in version 6.1.6.
- Attackers target the /roller-services/xmlrpc endpoint by submitting malicious POST requests containing large or base64-heavy bodies with methodCall payloads that trigger the vulnerable deserialization chain.
- Public PoC tools, such as those on GitHub (e.g., cveForge/CVE-2026-129448), allow attackers to execute arbitrary commands using Java Gadget chains like CommonsCollections5, often via shell commands or reverse shells.
